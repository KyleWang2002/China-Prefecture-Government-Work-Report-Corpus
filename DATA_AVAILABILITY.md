# Data availability

This repository publishes the parts of the project that are useful for evaluating the data-construction workflow without exposing the full private provenance log.

## Public in this repository

- city-level coverage metadata;
- city-year availability metadata;
- prefecture-level administrative-change metadata;
- processing and validation code;
- short illustrative text excerpts;
- methodological documentation.

## Not included in this release

- the full text corpus;
- the complete city-by-city source URL inventory;
- full yearbook, gazetteer, newspaper, or archival scans;
- internal collection notes.

The source URL inventory is intentionally kept private because it was assembled city by city and is central to maintaining the corpus over time. In addition, redistribution conditions differ across the archival sources from which historical reports were recovered.

The repository can therefore be used to evaluate coverage, methodology, and code without assuming that every source document is freely redistributable.
